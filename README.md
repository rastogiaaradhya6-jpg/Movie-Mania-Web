# 🎬 MovieMania — Search & Discover Movies

MovieMania is a simple, responsive movie discovery website built using HTML, CSS, and JavaScript. It allows users to browse movies, search for titles, filter movies by genre, view recommendations, and save their favourite movies.

## ✨ Features

- **Movie Search** — Search movies by their title.
- **Browse Movies** — Explore the available movie collection.
- **Genre Filters** — Filter movies according to different genres.
- **Recommendations** — Discover recommended movies.
- **Favourites** — Add or remove movies from your favourites list.
- **Favourite Counter** — Displays the total number of favourite movies.
- **Responsive Design** — Works across desktop and mobile screen sizes.
- **Interactive UI** — Dynamic movie cards with hover effects and interactive buttons.
- **Dark Theme** — Modern dark interface with pink accent colours.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/MovieMania.git
```

### 2. Navigate to the project directory

```bash
cd MovieMania
```

### 3. Run the project

Open `index.html` in your browser.

Alternatively, use a local development server such as VS Code Live Server.

## 🎨 Design

MovieMania uses a dark-themed interface designed to provide a clean movie-browsing experience.

- Background: Dark navy
- Cards: Dark purple/navy
- Accent: Pink
- Layout: Responsive CSS Grid
- Navigation: Browse and Favourites tabs
